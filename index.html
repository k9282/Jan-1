Mathematics in Biology / Fig. 1: Leaf Curve

This graph uses the polar equation r(θ) = sin(θ) × cos(θ), plotted as x = r cos(θ) and y = r sin(θ). The resulting curve demonstrates how polar equations can produce organic-looking mathematical forms.

Mathematics in Biology / Fig. 2: DNA Helix

This 3D plot shows a single helical curve using the parametric equations x = sin(t), y = cos(t), and z = 0.05 × t. It visually resembles one strand of a DNA helix. A second phase-shifted strand and connecting base pairs could be added to create a full double-helix model.
