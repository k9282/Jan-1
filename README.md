## Purpose

Jan-1 is an educational web application designed to demonstrate relationships between:

- mathematical functions;
- graphical representations;
- corresponding audio tones; and
- mathematical patterns appearing in biological forms.

The application also includes two biology-inspired visualizations:

- a **leaf pattern**;
- a **DNA helix**.

The goal is to provide a free and accessible tool for students, teachers, researchers, and anyone interested in exploring connections between mathematics, visualization, biology, and sound.
